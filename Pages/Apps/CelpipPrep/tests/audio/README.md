# Real recordings for the listening test

Put real audio or video here to replace the computer voice. The exam uses a file automatically when it exists.

Folder per test: `tests/audio/<TEST LETTER>/`

| File name | What it replaces |
|---|---|
| `LP-0.mp3` | Listening practice task recording |
| `L1-0.mp3`, `L1-1.mp3`, `L1-2.mp3` | Part 1, sections 1 to 3 |
| `L2-0.mp3`, `L3-0.mp3`, `L4-0.mp3`, `L6-0.mp3` | Parts 2, 3, 4 and 6 |
| `L5-0.mp4` | Part 5 video (an `.mp3` also works, audio only) |
| `LP.1.mp3`, `L1.1.mp3` ... `L3.6.mp3` | A read-aloud question in Parts 1 to 3 |

Current recordings:
- `A/L5-0.mp4`: Test A Part 5 discussion, made with Meta AI from 21 ten-second clips (2026-10-21), each checked against the script with offline speech recognition and trimmed to the spoken line.
